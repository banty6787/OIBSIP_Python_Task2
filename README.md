# BMI Calculator

A simple Python program that calculates Body Mass Index (BMI) using the user's weight and height.

## Features

- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI up to two decimal places
- Shows the BMI category:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Handles invalid input

## Formula

BMI = Weight / Height²

## How to Run

```bash
python bmi_calculator.py
